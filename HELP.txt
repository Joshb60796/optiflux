OptiFlux — Help and Definitions
================================

OptiFlux is a desktop Monte Carlo ray-tracing tool for designing LED and
COB (Chip-on-Board) illumination lenses. Units are millimetres (mm) unless
noted. The optical axis is +Z (light travels from source toward the target).


--------------------------------------------------------------------------
HEADER CONTROLS
--------------------------------------------------------------------------

Trace rays
  Run (or re-run) the ray-trace simulation with the current parameters.

Auto-run
  When checked, a new ray-trace starts after you release the mouse on a
  slider or side-view handle (or after a button / dropdown click).
  Dragging still updates lens geometry live (shape, convexity, position);
  the Monte Carlo map does not start until the pointer is up.
  When unchecked, OptiFlux does not trace, does not redraw thousands of
  side-view ray paths, and does not refresh CAD mesh estimates — so you
  can move lenses, blockers, sizes, and surfaces without the UI stalling.
  Press Trace rays when you want a map again.

Export STL / Export STEP
  Write CAD files of the current lens surfaces for 3D printing or machining.
  Coordinates are in millimetres. Mesh density is set in Optics → CAD export
  (max vertex length and max facet angle). Optional print flanges (radial
  width and axial thickness) are added to the CAD only — they are not in
  the ray-trace. A companion *_tube.txt lists each element OD, flange
  thickness, groove-center Z, groove center-to-center, source-to-tube-front,
  and last-groove-to-focus (Target Z).
  Check “STL as print halves” to cut each lens at the flange mid-plane and
  write *_front.stl / *_rear.stl — a flat build face for resin printing;
  glue the halves with the same photopolymer.
  Export polish lap writes a cylindrical tool whose working face is the
  negative of the lens surface (coat with abrasive and spin the lens or
  the tool). The opposite end has a 1/4-20 tap hole. Default is STL.
  Export 4-axis polish writes GRBL for a spherical tool on A (optical
  axis). Default extension is .nc for Candle.

Reset defaults
  Restore factory starting parameters and re-trace.

Presets
  Quick starting points (single LED, COB arrays, rectangular FOV designs).

Save / Load design
  Header buttons: Design → Save… and Design → Load…
  Saves the full configuration to a JSON file under the designs/ folder
  (source, all lens elements, materials, FOV, MLA, blockers, ray counts).
  Load restores every control and re-traces. Optional notes are stored
  in the file and shown when loading.

3D view
  Header button: opens an interactive isometric 3D window of the source,
  lens stack, absorbing blockers, target plane, and FOV outline. Opens
  like the Target Plane: Y vertical, +X toward you (down-right), +Z
  receding (top-right). Left-drag to rotate; right-drag to zoom
  (matplotlib toolbar also available). Update refreshes after parameter
  changes; sample ray paths appear when a trace has been run.


Help
  Opens this document in a scrollable window. Laser n calibration has
  its own “How to calibrate…” button under Optics.


--------------------------------------------------------------------------
SOURCE (LED / COB)
--------------------------------------------------------------------------

Mode — single vs cob
  Single: one rectangular emitter die.
  COB: a grid of dies (rows × cols) at a pitch.

Pitch X / Pitch Y
  Centre-to-centre spacing of dies in a COB array (mm).

Die width / Die height
  Physical size of each emitting rectangle (mm). Range is 0.1–50 mm so
  large modules (for example a 35×35 mm LED) can be entered.

Source Z
  Axial position of the emitter plane (mm). Usually 0.

Half-angle
  Hard cutoff of the emission cone (degrees). Inside that cone the source
  is Lambertian: radiance is uniform, so intensity falls as cos(θ). That
  puts more rays (and more power) near the optical axis than at the rim
  of the cone — that is correct LED physics, not a sampling bug. The
  side view draws the first segment of every stored ray so the cone
  rim stays visible even when those rays miss the lens.

Wavelength
  Design wavelength in nanometres (nm). Used for refractive index lookup.

Tilt X / Tilt Y
  Global tip of all die normals (degrees). Positive tilt tips the local +Z
  toward +Y (tilt X) or +X (tilt Y).

MLA (micro-lens array)
  When enabled, Element 1 is replicated once per COB die as a lenslet.
  Fill factor and pitch limit each lenslet aperture so neighbours do not
  interfere. Optional aim steers each channel toward the FOV centre.


--------------------------------------------------------------------------
OPTICS (LENS STACK)
--------------------------------------------------------------------------

Element 1 … Element 8
  Up to eight sequential lenses along +Z. Disabled elements are ignored.
  Use collapse controls to hide unused slots.

Enabled
  Include this element in the ray-trace and CAD export.

--------------------------------------------------------------------------
LASER n CALIBRATION (PRINTED RESIN)
--------------------------------------------------------------------------

Open Optics → Laser n calibration, or press “How to calibrate…” there.
The coaxial (centered) shot does not determine n. It only sets the origin
on the card. n comes from how far the dot moves when you shift the laser
sideways without tilting it. OptiFlux traces the same +Z pencil the
simulator uses (Snell at every surface).

What you need
  The printed lens or group whose radii and thicknesses match the loaded
  design (measure center thickness if you can). A laser pointer — red
  ≈ 650 nm, green ≈ 532 nm, HeNe = 632.8 nm. A card you can mark, a
  ruler, and a way to keep the beam parallel to +Z. Never look into the
  beam or a reflection off the lens.

Coordinate reminder
  Light travels +Z. X is horizontal, Y is vertical (Target Plane). All
  values are millimetres. Laser Z is the pointer (usually 0). Screen /
  card Z is the card on the same axis (Target Z if the card is at the
  design throw).

Setup
  Load the printed design. Hold the first vertex toward the laser.
  Place the card square to the axis at a known Z, not right at the
  focus — the dot should still move when you change height.

Step 1 — coaxial (alignment)
  Aim +Z through the center. Mark the dot. If that mark is your origin,
  Coaxial dot X and Y are 0. If the card already has axes, enter the
  measured coaxial X and Y. The fit subtracts this reading.

Step 2 — shift the laser
  Translate the pointer by a known X and/or Y (for example +5 mm in Y).
  Do not tilt. Enter Laser offset X and Y. Stay inside the clear
  aperture, not on the rim.

Step 3 — mark the shifted dot
  Measure the new dot in the same axes. Enter Shifted dot X and Y.
  Confirm Laser Z, Screen Z, and wavelength.

Step 4 — Fit n
  Press “Fit n from laser dots”. A good residual is a fraction of a
  millimetre. Element 1 lensmaker EFL is shown as a check.

Step 5 — Apply
  Press “Apply fitted n to Custom / Formlabs”. Writes Custom n and
  switches Formlabs / Custom elements to Custom. Catalog glass is
  unchanged.

If the fit looks wrong
  Large residual: Screen Z or axes are inconsistent. n far from
  1.50–1.58 for Clear: printed thickness or radii do not match the
  file. On-axis only: you must shift. Do not tilt the pointer. If the
  card is at the focus, move it — the dot will not move with n.

This is one n at one wavelength. It does not include scatter, layer
lines, polish haze, or beam width.

Lock circular outline (Y = X)
  Keeps the clear aperture round so a circular tube can hold the lens.
  On by default. Turn off only if you need an elliptical outline.
  Surface mode (cylinder / biconic) is unchanged — only the outer shape
  is forced circular. Set each element’s semi-aperture if you want
  different ODs; the flange radial width is then added on export.

Copy from
  Dropdown on each element. Pick another slot (for example Element 1) to
  copy its radii, thickness, apertures, material, and surface mode onto
  this slot and enable it. The copy sits after the previous enabled
  element’s “Air gap after” — set that gap on the source lens to space
  the duplicate.

Lens type
  Library starting shapes (plano-convex, biconvex, ball, …) that set R1/R2
  signs and proportions. Custom leaves radii fully free.

Ball lens (full sphere)
  A complete glass/plastic sphere. |R| is the radius: thickness becomes 2R
  and the clear semi-aperture becomes R. Sequential tracing uses the shared
  sphere (enter the source-facing hemisphere, exit the far side). CAD
  exports a true sphere (no print flange). Balls collect a wide Lambertian
  cone from a surface emitter — set emission half-angle to 90° for a full
  180° hemisphere — and are a classic collimator when the source sits near
  the front focal point (n R / (2(n−1)) − R from the first vertex).

|R| magnitude
  Scales library-type radii while preserving the shape family.

Material
  Glass or plastic from the catalog. New elements default to Formlabs
  Clear Resin (the SLA prototype material). PMMA, N-BK7, and others
  remain in the dropdown.
  Index n is taken at the source wavelength.

Surface mode
  rotational — same power in X and Y (circular beam tendency).
  biconic — independent Rx and Ry (rectangular footprints).
  cylinder_x — power only in X (plano in Y).
  cylinder_y — power only in Y (plano in X).

R1 / Rx front, R2 / Rx rear
  Vertex radii of curvature (mm). Sign convention: positive R1 is convex
  toward the source (−Z side of the front surface). R2 negative is typical
  for a biconvex rear.

R1y / R2y
  Y-meridian radii for biconic or cylinder_y surfaces.

Thickness
  Centre thickness of the lens (mm).

Air gap after
  Air space after this element before the next (mm).

Semi-aperture X / Y
  Clear semi-diameter (mm). Elliptical aperture uses both X and Y.

Conic k, Asphere A4
  Standard even asphere terms on each surface.

Lens Z start
  Z position of the first surface vertex of Element 1 (mm).


--------------------------------------------------------------------------
TARGET AND FIELD OF VIEW (FOV)
--------------------------------------------------------------------------

Target Z
  Distance from Z = 0 to the irradiance plane (mm).

FOV width / FOV height
  Rectangular region of interest on the target plane (mm). This is the
  “camera field” or illumination zone you want to fill. Range is 5–500 mm
  (a 200×200 mm field at 150 mm throw is valid). The recorded map grows
  automatically so the FOV is never clipped.
  Drag the violet FOV bar ends on the side views, or the diamond grips on
  the target-plane rectangle, to change the size the same way you resize
  a lens or blocker. Drag the bar centre / rectangle interior to move it.

Focus group on target
  Moves the entire lens group along Z (internal gaps stay fixed) to the
  position where each point on the source images most sharply onto the
  FOV plane — the flashlight conjugate, where the emitter shape becomes
  visible. This is not the same as the optimizer’s “sharpest illumination
  border” (flood edge). A true image of the source needs throw ≳ 4× EFL;
  otherwise the button still picks the least-blurred station on the bench.

Lens Z start
  First-vertex Z of the group. Range is 0.2–1000 mm so a group can sit
  anywhere between a source at 0 and a target at 150 mm (or further).

FOV aspect W/H
  Width divided by height. Lock aspect updates height when width changes.

FOV center X / Y
  Centre of the rectangular FOV on the target plane (mm).

Map half-width / half-height
  Extent of the recorded irradiance map (mm). Should be larger than the FOV.
  Zooming the target plane is a camera only: you can pull back onto a
  multi-metre virtual wall, but the recorded map and collection stay on
  this rectangle. Hits outside the map stay visible as individual rays.

Map resolution
  Number of bins across the map width (higher = smoother, slower).

Design optics for rectangular FOV
  Seeds cylindrical or biconic powers estimated for the current FOV aspect.

Swap anamorphic X ↔ Y
  Exchanges cylinder/biconic X and Y powers (fixes a 90° rotated footprint
  without changing the FOV size).

Rotate optics 90° vs FOV
  Swaps FOV width with height AND swaps anamorphic X/Y powers so the design
  tracks a 90° rotation of the rectangular target relative to the lenses.


--------------------------------------------------------------------------
SIMULATION
--------------------------------------------------------------------------

Rays to trace
  Monte Carlo sample count for the target-plane irradiance map. The
  simulation splits this count across progressive batches. Raise map
  resolution as well if the heatmap still looks blocky after more rays.

Side-view ray paths
  How many individual ray polylines to store for the side view and for
  optional ray-class overlays. Raising this value draws more rays and
  more colored endpoints on the target plane.

Color partial lens rays (target)
  When checked, both the target plane and the side view color rays by class:
    • Cyan — rays that missed all lenses
    • Amber — rays that went through some but not all enabled elements
    • Green — rays that interacted with every enabled element in the stack
  Off by default. Raise “Side-view ray paths” for denser overlays.


--------------------------------------------------------------------------
LEFT PANEL (collapsible sections)
--------------------------------------------------------------------------

Source, Optics, Blockers, Target, Simulation, and Optimizer sections each
have a ▶ / ▼ header. Click the triangle (or the header bar) to expand or
collapse. All sections start collapsed when the program opens so the panel
stays short; expand only what you need. A vertical scrollbar on the right
edge of the panel scrolls the full list of sections.

Lens Element 1…8 still collapse individually inside Optics (same as before).


--------------------------------------------------------------------------
OPTIMIZER (left panel — all optimization lives here)
--------------------------------------------------------------------------

Goal
  Rectangular FOV fill — pack light into the FOV rectangle (optional
  anamorphic extras if you allow adding lenses).
  Sharpest focus — make the illumination border as crisp as possible
  (does not add lenses).
  Maximum evenness — flatten irradiance from edge to edge of the FOV
  (does not add lenses).
  Collimated beam to FOV — minimize the angular spread of rays that
  reach the FOV so the beam stays parallel on the throw. Does not add
  lenses. A ball near the source is a good starting point.

Allow adding lenses
  Off by default. When on, rectangular fill injects extra elements
  (crossed cylinders / biconic / relays) up to the max extra slider
  and keeps them unless the extra-lens stack collapses the FOV. A
  small drop in collection from extra surfaces is expected. The stack
  still cannot exceed 8 elements.

Max extra lenses
  0–8. 1 = biconic singlet; 2 = crossed cylinders (X then Y);
  3+ adds relay / field elements. Unused if the goal is focus,
  evenness, or collimated beam, or if “Allow adding lenses” is off.

Aspect-match / fill / uniformity weights
  How strongly the score penalizes wrong footprint aspect, under-sized
  illumination, or non-uniform FOV irradiance.

Rays per evaluation / Max evaluations
  Coarser and fewer for speed; higher for a more stable final design.


--------------------------------------------------------------------------
METRICS (READOUTS)
--------------------------------------------------------------------------

Collimation RMS (FOV rays)
  Power-weighted RMS angle of target-plane rays (preferring those inside
  the FOV) from their mean direction. 0° is a perfectly parallel bundle.

Collection efficiency
  Power inside the rectangular FOV divided by source power. Light that
  only hits the target plane outside the FOV (including the zoomed-out
  wall) is not collected.

FOV flux (fraction)
  Of the light recorded on the heatmap, the fraction that landed inside
  the rectangular FOV.

Uniformity
  1 − coefficient of variation of irradiance inside the FOV (higher is more
  even). Alternate definitions may use min/max.

Illumination edge sharpness
  Mean irradiance gradient along the half-max contour of the target-plane
  map (higher = crisper border). This is what “Sharpest focus” maximizes.

Footprint aspect σx/σy
  Power-weighted second-moment width ratio of the illuminated pattern.

Target FOV aspect W/H
  FOV width / FOV height.

Aspect error
  Relative mismatch between footprint aspect and FOV aspect.

Coverage
  Fraction of FOV bins that are meaningfully lit.

EFL (element 1)
  Approximate thin-lens effective focal length from the lensmaker formula.


--------------------------------------------------------------------------
BLOCKERS (BODIES / TUBES / STOPS)
--------------------------------------------------------------------------

Left panel: BLOCKERS · absorbing panels / stops

  Simulates light-absorbing enclosure walls (lens barrel, snoot, baffles)
  and mechanical stops.

  Add body (rect · horizontal) — default for rectangular panels
    Four walls of a rectangular tube along +Z (top/bottom/left/right).
    In the side view these appear as *horizontal* lines at ± half-height —
    like a camera body or rectangular snoot. Rays inside the bore pass;
    rays that hit a wall are absorbed.

  Add tube (circle · tube) — default for circular shape
    Circular cylinder along the optical axis (lens barrel / pipe / snoot).
    Side view shows top and bottom generators as horizontal lines.
    On-axis light through the bore is free; wall hits absorb.

  Add stop (vertical / face-on)
    Z-normal aperture stop or solid disk (iris). Appears as a vertical
    slab in the side view. Optional central hole = open aperture.

  Length along Z sets how long bodies/tubes are. Drag the red square to
  move the center along Z.


--------------------------------------------------------------------------
VIEWS
--------------------------------------------------------------------------

Side views (Y–Z and X–Z)
  Two stacked meridional cuts share the Z axis:
    • Top (Y–Z) — shows cylinder_y and rotational power in Y
    • Bottom (X–Z) — orthogonal cut; shows cylinder_x and rotational power in X
  The bar under both plots moves the whole lens group along Z (internal
  air gaps stay fixed). Left is toward the source; right is toward the
  target. Same value as Optics → First vertex Z. Drag updates geometry
  live; release re-traces if Auto-run is on.
  Scroll to zoom; right-drag to pan. Handles on each lens:
    • Yellow centre square — move that lens along Z (neighbours stay fixed)
    • Purple dots on front/rear vertices — drag to set R₁ / R₂
    • Top/bottom diamonds — clear semi-aperture
  Grey slabs = absorbing blockers (red square = Z drag).
  Violet bar at Target Z = FOV (diamonds resize, square moves).
  Side-view zoom is a camera: it is not reset when a progressive batch
  finishes. Release the mouse to re-trace (only if Auto-run is on).

3D isometric view
  Header “3D view” — night optical bench: glowing LED chip, glass lens
  shells, and the same target-plane irradiance map as the main window
  painted on a phosphor screen. Purple frame = FOV. Left-drag rotate,
  right-drag zoom. Update refreshes after a trace; Log map matches the
  main-window log scale. Reset camera returns to the Y-up three-quarter
  view (from +X / −Z).

Target plane (X–Y)
  Irradiance map at Target Z. Purple rectangle = FOV with grab handles on
  corners and edges. White cross = power centroid. Scroll / right-drag as
  in the side view. Zoom does not grow the recorded map; display-path hits
  stay drawn so rays remain visible when you zoom in.

Profiles panel (left of target plane)
  Always-visible line cuts along X (Y=0), Y (X=0), and the XY diagonal, with
  FOV boundary markers. The optimizer uses profile-fill from these cuts.

Buy list
  Commercial-style lens parameters (diameters, radii, thickness, material,
  estimated EFL) for quoting from catalog suppliers.


--------------------------------------------------------------------------
CAD EXPORT (Optics panel · 3D print quality)
--------------------------------------------------------------------------

Max vertex length (mm)
  Longest allowed edge between adjacent mesh vertices on the clear
  aperture. Smaller values (0.10–0.20 mm) hide print facets; 0.25 mm
  is a good starting point. Larger values make smaller, coarser files.

Max facet angle (°)
  Largest allowed angle between neighbouring facets on a curved surface.
  1–2° is typical for a smooth print; 5–10° is a preview mesh.

STL as print halves
  Cuts each singlet at the flange mid-plane (z_front + thickness/2) and
  writes *_front.stl and *_rear.stl. Each half has a flat disk on the cut
  so a resin printer can build from that face; glue the halves with the
  same photopolymer.

Export polish lap STL
  One cylinder per selected face (front / rear / both) and per enabled
  element. The working end is the negative of that optical surface inside
  a circular nest (clear aperture + 0.2 mm slip) so the lens can sit on
  the matching shape. Coat the face with abrasive and spin the lens or
  the cylinder. The opposite end is a coaxial 1/4-20 UNC hole, modeled
  as a #7 tap drill (5.105 mm) × 12.7 mm deep — tap after printing.
  Wall beyond the nest is set by “Wall beyond clear aperture”. A
  companion *_tool.txt lists OD, length, well ID, and hole size.
  Coordinates: mount face at Z = 0, optical face toward +Z.

Export 4-axis polish (.nc)
  GRBL program for a mill like the Genmitsu Prover 3030 Ultra with the 4th
  axis on A. Mount a printed lens half so its optical axis is the A-axis
  (along machine X). A spherical abrasive in the vertical spindle approaches
  radially in Z. Tool-center path is the optical meridian offset by the ball
  radius along the air normal.
    • X0 = flange mid-plane (the printed flat). X+ toward the optical surface.
    • Y = 0 (stay in the vertical plane through A).
    • Z = radial distance of the ball centre from A.
    • A = rotation of the half (degrees, always increasing).
  Helical: one pass rim → vertex while A winds. Rings: at each meridian
  station, A spins in place then steps inward. Allowance is extra offset
  along the normal (positive = lighter cut). Default extension is .nc for
  Candle. Face = both writes *_front.nc and *_rear.nc.

The panel shows the resulting ring × segment count, rim spacing, and
triangle estimate. Both STL and STEP use this tessellation (STEP is
exported as a triangulated solid). Settings are saved with the design.


--------------------------------------------------------------------------
PHYSICS NOTES
--------------------------------------------------------------------------

Monte Carlo
  Random rays are sampled from each die; statistics converge as ray count
  increases. Results are noisy at low ray counts.

Snell + Fresnel
  Refraction uses Snell’s law; transmission is reduced by Fresnel reflection
  at each interface when Fresnel is enabled.

TIR (total internal reflection)
  When a ray cannot refract out of glass, it is absorbed by default (or
  reflected if bounce mode is enabled).

MLA aim
  Per-die emission tilt and optical-center offset toward the FOV centre,
  clamped so lenslets stay inside their pitch cells.


--------------------------------------------------------------------------
TIPS
--------------------------------------------------------------------------

• Start with one element, Trace, then enable more elements only if needed.
• For rectangular FOV, try “Crossed cylinders” or “Biconic singlet”, then
  open OPTIMIZER, pick Rectangular FOV fill, and run Optimize. Leave
  “Allow adding lenses” off unless you want extra anamorphic elements.
• If the footprint looks 90° rotated, use Swap anamorphic X↔Y or Rotate
  optics 90° vs FOV.
• Increase rays (15k–50k) before trusting uniformity numbers.
• Collapse disabled elements to keep the side panel short.
